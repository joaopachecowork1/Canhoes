# Fonts

Latin variable files from Google Fonts, committed so the build works offline. Loaded with `next/font/local` in `app/layout.tsx`.

| File | Font | License |
|---|---|---|
| `orbitron-latin.woff2` | [Orbitron](https://fonts.google.com/specimen/Orbitron) | [SIL Open Font License 1.1](https://openfontlicense.org) |
| `dm-sans-latin.woff2` | [DM Sans](https://fonts.google.com/specimen/DM+Sans) | [SIL Open Font License 1.1](https://openfontlicense.org) |
| `jetbrains-mono-latin.woff2` | [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) | [SIL Open Font License 1.1](https://openfontlicense.org) |

To update one, download the `/* latin */` file from `https://fonts.googleapis.com/css2?family=<Font>:wght@<weights>` with a browser user agent.
